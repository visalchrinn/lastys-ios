# Khmer translations needed

Every user-facing English string in the app. None has a Khmer translation yet (the string catalog has no Khmer values). Fill the Khmer column, then it goes into `Localizable.xcstrings`.

Notes: `%@` and `%lld` are filled in by the app (a name or a number); keep them in the Khmer text, in whatever order reads naturally. Dates are formatted by iOS and need no translation. Use the glossary terms (Lastys ID, Relationship, Partner, Scan, Taken, Verified Single...) consistently, and decide once how each is written in Khmer.
